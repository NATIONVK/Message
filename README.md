# Message ♥
An aesthetic, responsive secret-message website by NATIONVK.

## Features
- Animated envelope interaction
- Hidden letter reveal and close interaction
- Romantic dark theme
- Responsive layout for mobile and desktop
- Keyboard accessible envelope
- No external dependencies

## Run locally
Open `index.html` in any modern browser.

## Deploy with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save and wait for the deployment to finish.

## Customize the letter
Edit the text inside the `<p id="message">` element in `index.html`.
You can also change the greeting and signature in the letter section.

## Privacy note
This is a public repository. Anything written directly in the source code can be viewed by visitors. Do not put private, identifying, or sensitive messages or information here.
